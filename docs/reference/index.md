# Overview

The technical documentation for mesoscopy comes in two parts.

- The [mesoscopy CLI](cli-mesoscopy.md) documentation describes the commands of mesoscopy's command line
  interface. It is a quick reference to what mesoscopy can do and matches `mesoscopy --help` in a terminal.
- The [mesoscopy API](api-mesoscopy.md) documentation describes the modules and functions mesoscopy is built
  from. Read it to [use mesoscopy as a library](../how-to/using-mesoscopy-as-a-library.md) or to
  [contribute](../contributing.md).
