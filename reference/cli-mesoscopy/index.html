    mesoscopy

    Widefield calcium imaging analysis pipeline.

    Usage:

    mesoscopy [OPTIONS] COMMAND [ARGS]...

    Options:

      --version  Show the version and exit.
  --help     Show this message and exit.

    Subcommands

    • align: Align frame timestamps to a behaviour session.
    • convert: Convert raw recordings to NWB or HDF5.
    • export: Export mesoscopy files to other formats.
    • inspect: Inspect an NWB recording and its processing progress.
    • postprocess: Postprocess extracted activity.
    • preprocess: Extract haemodynamics-corrected ∆F/F from a recording.
    • process: Analyse preprocessed or registered recordings.
    • register: Register recordings to an anatomical template.
    • report: Generate an HTML report for a pipeline stage.
    • sample: Save one frame of an HDF5 recording as a PNG.
    • start-time: Print a recording's start time.

    align

    Align frame timestamps to a behaviour session.

    PATH is a preprocessed or registered HDF5 recording. Give the session start with --behaviour-json, or with --session-start and --behaviour-id. Writes /timestamps_aligned, in seconds from the session start, into PATH.

    Usage:

    mesoscopy align [OPTIONS] PATH

    Options:

      --session-start TEXT   Behaviour session start time in ISO format, instead
                         of --behaviour-json.
  --behaviour-json FILE  Visiomode behaviour session JSON file giving the
                         session start.
  --behaviour-id TEXT    Behaviour session identifier, required with
                         --session-start. Defaults to the --behaviour-json
                         file name.
  --max-offset FLOAT     Largest allowed offset between the first frame and
                         the session start, in seconds.  [default: 600.0]
  --help                 Show this message and exit.

    convert

    Convert raw recordings to NWB or HDF5.

    Usage:

    mesoscopy convert [OPTIONS] COMMAND [ARGS]...

    Options:

      --help  Show this message and exit.

    Subcommands

    • h5: Convert a raw HDF5 recording to NWB.
    • video: Convert a raw video recording to NWB.

    h5

    Convert a raw HDF5 recording to NWB.

    INPUT_PATH is a raw dual-channel HDF5 recording. Fill in the subject and session metadata with --meta or the metadata options. Writes an NWB file named after INPUT_PATH.

    Usage:

    mesoscopy convert h5 [OPTIONS] INPUT_PATH

    Options:

      -o, --out-dir PATH           Output directory, created if missing.
  -l, --link-only              Link the raw frames instead of copying them.
                               The NWB file then needs the raw HDF5 file to
                               stay in place.
  -f, --frames-group TEXT      HDF5 dataset holding the frames.  [default:
                               frames]
  -t, --timestamps-group TEXT  HDF5 dataset holding the timestamps.  [default:
                               timestamps]
  -m, --meta PATH              Subject and session metadata file in YAML or
                               JSON format.
  --subject-id TEXT            Subject identifier.
  --sex [m|f]                  Subject sex.
  --genotype TEXT              Subject genotype.
  --species TEXT               Subject species.
  --strain TEXT                Subject strain.
  --dob TEXT                   Subject date of birth as YYYY-MM-DD.
  --description TEXT           Session description.
  --experimenter TEXT          Experimenter name.
  --lab TEXT                   Lab the session was recorded in.
  --institution TEXT           Institution the session was recorded in.
  --help                       Show this message and exit.

    video

    Convert a raw video recording to NWB.

    INPUT_PATH is an AVI or MP4 recording and --ts-path its frame timestamps file. Fill in the subject and session metadata with --meta or the metadata options. Writes an HDF5 file and an NWB file named after INPUT_PATH.

    Usage:

    mesoscopy convert video [OPTIONS] INPUT_PATH

    Options:

      -o, --out-dir PATH          Output directory, created if missing.
  -t, --ts-path PATH          Frame timestamps file, plain text or delimited.
  -d, --ts-delimiter [,|    | ]  Delimiter of the timestamps file.
  -c, --ts-column INTEGER     Column of the timestamps file to read, needed
                              when it has more than one.
  --ts-has-header             The timestamps file has a header row.
  -l, --hdf5-only             Write the HDF5 file only, without converting it
                              to NWB.
  -m, --meta PATH             Subject and session metadata file in YAML or
                              JSON format.
  --subject-id TEXT           Subject identifier.
  --sex [m|f]                 Subject sex.
  --genotype TEXT             Subject genotype.
  --species TEXT              Subject species.
  --strain TEXT               Subject strain.
  --dob TEXT                  Subject date of birth as YYYY-MM-DD.
  --description TEXT          Session description.
  --experimenter TEXT         Experimenter name.
  --lab TEXT                  Lab the session was recorded in.
  --institution TEXT          Institution the session was recorded in.
  --help                      Show this message and exit.

    export

    Export mesoscopy files to other formats.

    Usage:

    mesoscopy export [OPTIONS] COMMAND [ARGS]...

    Options:

      --help  Show this message and exit.

    Subcommands

    • deltaf: Export a ∆F/F recording as a video.
    • nwb: Make a shareable copy of an NWB file.
    • timestamps: Export a recording's timestamps as text.

    deltaf

    Export a ∆F/F recording as a video.

    PATH is an HDF5 or NWB ∆F/F recording. Writes _deltaf.mp4.

    Usage:

    mesoscopy export deltaf [OPTIONS] PATH

    Options:

      --out-path PATH  Output directory for the video.
  --help           Show this message and exit.

    nwb

    Make a shareable copy of an NWB file.

    NWB_PATH is an NWB file that links to the HDF5 files mesoscopy writes. Writes a self-contained copy with the linked data copied in.

    Usage:

    mesoscopy export nwb [OPTIONS] NWB_PATH

    Options:

      --out-path FILE  Path of the exported NWB file. Defaults to
                   <name>_export.nwb next to NWB_PATH.
  --help           Show this message and exit.

    timestamps

    Export a recording's timestamps as text.

    PATH is an HDF5 or NWB recording. Writes _timestamps.txt with one timestamp per line.

    Usage:

    mesoscopy export timestamps [OPTIONS] PATH

    Options:

      --out-dir PATH  Output directory for the timestamps file.
  --help          Show this message and exit.

    inspect

    Inspect an NWB recording and its processing progress.

    INPUT_PATH is an NWB file. Pass --acquisition, --deltaf or --registered to open that data in a napari viewer. Prints the session metadata and which pipeline stages have run.

    Usage:

    mesoscopy inspect [OPTIONS] INPUT_PATH

    Options:

      --meta-only    Print the metadata only. This is the default.
  --acquisition  Also open the raw acquisition in a viewer.
  --deltaf       Also open the ∆F/F series in a viewer.
  --registered   Also open the registered ∆F/F series in a viewer.
  --help         Show this message and exit.

    preprocess

    Extract haemodynamics-corrected ∆F/F from a recording.

    PATH is a raw dual-channel HDF5 or NWB recording. Use --crop and --bins to shrink the frames, and --skip-start and --skip-end to drop frames at either end. Writes _preprocessed.h5, and links it into PATH when PATH is an NWB file.

    Usage:

    mesoscopy preprocess [OPTIONS] PATH

    Options:

      -o, --out_dir PATH    Output directory for the preprocessed recording.
  --chunks INTEGER      Frames loaded into memory at a time.  [default: 100]
  --crop INTEGER        Pixels to crop from each edge.  [default: 0]
  --bins INTEGER        Pixel binning factor.  [default: 2]
  --channel-means-only  Stop after extracting the channel means.
  --use-means           Separate the channels by their mean intensity instead
                        of their standard deviation.
  --flip-channels       Swap the two channels after separating them.
  --interim_dir PATH    Directory under which intermediate files are kept
                        until preprocessing ends.  [default: interim/]
  --skip-start INTEGER  Frames to drop from the start of the recording.
  --skip-end INTEGER    Frames to drop from the end of the recording.
  --no-qa               Skip the automatic quality control checks.
  --help                Show this message and exit.

    process

    Analyse preprocessed or registered recordings.

    Usage:

    mesoscopy process [OPTIONS] COMMAND [ARGS]...

    Options:

      --help  Show this message and exit.

    Subcommands

    • connectivity: Measure pairwise connectivity between regions.
    • decode: Decode the stimulus or lever push from region activity.
    • metrics: Measure trial response metrics from peri-event traces.
    • peri-event: Cut per-trial windows around a behavioural event.
    • regions: Extract the mean ∆F/F of each brain region.
    • regression: Regress behavioural variables onto each ∆F/F pixel.
    • smooth: Smooth a ∆F/F recording.
    • zscore: Z-score a ∆F/F recording pixel by pixel.

    connectivity

    Measure pairwise connectivity between regions.

    PATH is a _perievent.csv from process peri-event, measured over each trial's cue-to-response epoch, or a _regions.csv from process regions, measured over the whole recording. Add --with-te for transfer entropy and --with-rolling for connectivity in sliding windows. Writes _connectivity.csv with one row per region pair and trial group.

    Usage:

    mesoscopy process connectivity [OPTIONS] PATH

    Options:

      -o, --out_dir PATH              Output directory for the connectivity table.
  --response <FLOAT FLOAT>...     Response window START END, seconds relative
                                  to the event, end inclusive. Defaults to all
                                  post-event samples.
  -t, --trials FILE               Trials CSV to join by trial_index, for peri-
                                  event files without trials columns.
  --min-trials INTEGER RANGE      Trial groups with fewer trials get empty
                                  metrics.  [default: 10; x>=1]
  --mask-response / --no-mask-response
                                  End cue-aligned epochs at each trial's
                                  response, or at the median response time for
                                  trials without one.  [default: mask-
                                  response]
  --min-rt FLOAT RANGE            Drop trials with a response time below this,
                                  in seconds.  [default: 0.2; x>=0]
  --response-pad FLOAT RANGE      Extend each epoch past the response by this,
                                  in seconds.  [default: 0.0; x>=0]
  --max-lag FLOAT RANGE           Largest lag searched for the peak cross-
                                  correlation, in seconds.  [default: 0.5;
                                  x>=0]
  --mi-neighbours INTEGER RANGE   Neighbours for the mutual information
                                  estimator.  [default: 3; x>=1]
  --with-mi / --no-mi             Estimate the mutual information of each
                                  pair, which is the slowest metric.
                                  [default: with-mi]
  --te-history INTEGER RANGE      Past samples of the target the transfer
                                  entropy conditions on.  [default: 1; x>=1]
  --te-surrogates INTEGER RANGE   Surrogates for the transfer entropy
                                  z-scores. 0 leaves the z-scores out.
                                  [default: 200; x>=0]
  --with-te / --no-te             Estimate the transfer entropy of each pair
                                  in both directions.  [default: no-te]
  --with-rolling / --no-rolling   Also write <stem>_connectivity-rolling.csv
                                  with connectivity in windows sliding over
                                  the peri-event window.  [default: no-
                                  rolling]
  --rolling-window FLOAT RANGE    Length of the rolling windows, in seconds.
                                  [default: 0.5; x>0]
  --rolling-step FLOAT RANGE      Time between the starts of consecutive
                                  rolling windows, in seconds.  [default: 0.1;
                                  x>0]
  --seed INTEGER                  Random seed for the surrogates.  [default:
                                  42]
  --help                          Show this message and exit.

    decode

    Decode the stimulus or lever push from region activity.

    PATH is a go/no-go *_perievent.csv from process peri-event. Pick what to decode with --label, and add --with-rolling to decode in sliding windows. Writes _label-

    Usage:

    mesoscopy process decode [OPTIONS] PATH

    Options:

      -o, --out_dir PATH              Output directory for the decoding tables.
  -l, --label [stim|response]     Decode the go/no-go stimulus or the lever
                                  push.  [default: stim]
  --response <FLOAT FLOAT>...     Response window START END, seconds relative
                                  to the event, end inclusive. Defaults to all
                                  post-event samples.
  -t, --trials FILE               Trials CSV to join by trial_index, for peri-
                                  event files without trials columns.
  --min-trials INTEGER RANGE      Trials each class needs for a trial group to
                                  be decoded.  [default: 10; x>=1]
  --mask-response / --no-mask-response
                                  End the epoch at the response rather than at
                                  the response window end.  [default: mask-
                                  response]
  --per-trial-end                 End each trial's epoch at its own response
                                  instead of the median response time.
  --min-rt FLOAT RANGE            Drop trials with a response time below this,
                                  in seconds.  [default: 0.2; x>=0]
  --response-pad FLOAT RANGE      Extend the epoch past the response by this,
                                  in seconds.  [default: 0.0; x>=0]
  --folds INTEGER RANGE           Cross-validation folds.  [default: 5; x>=2]
  --repeats INTEGER RANGE         Cross-validation repeats, each with a fresh
                                  split.  [default: 10; x>=1]
  --shuffles INTEGER RANGE        Label shuffles for the chance level and
                                  p-values. 0 leaves them out.  [default: 200;
                                  x>=0]
  --with-rolling / --no-rolling   Also write <stem>_label-<label>_decoding-
                                  rolling.csv with scores in windows sliding
                                  over the peri-event window.  [default: no-
                                  rolling]
  --rolling-window FLOAT RANGE    Length of the rolling windows, in seconds.
                                  [default: 0.5; x>0]
  --rolling-step FLOAT RANGE      Time between the starts of consecutive
                                  rolling windows, in seconds.  [default: 0.1;
                                  x>0]
  --baseline <FLOAT FLOAT>...     Window START END, seconds relative to the
                                  event, end exclusive, whose mean gives the
                                  rolling chance level. Defaults to every
                                  sample before the event.
  --seed INTEGER                  Random seed for the splits and the shuffles.
                                  [default: 42]
  --help                          Show this message and exit.

    metrics

    Measure trial response metrics from peri-event traces.

    PATH is a *_perievent.csv from process peri-event. Set the windows with --baseline and --response, and the onset method with --onset. Writes _metrics.csv per trial, _metrics-session.csv per trial group, and the bootstrapped mean-trace tables _metrics-boot.csv and _traces-boot.csv.

    Usage:

    mesoscopy process metrics [OPTIONS] PATH

    Options:

      -o, --out_dir PATH              Output directory for the metrics tables.
  --baseline <FLOAT FLOAT>...     Baseline window START END, seconds relative
                                  to the event, end exclusive. Defaults to all
                                  pre-event samples.
  -t, --trials FILE               Trials CSV to join by trial_index, for peri-
                                  event files without trials columns.
  --response <FLOAT FLOAT>...     Response window START END, seconds relative
                                  to the event, end inclusive. Defaults to all
                                  post-event samples.
  --onset [sd|peak|extrapolate]   Onset by a baseline SD threshold, an
                                  amplitude fraction threshold, or a line
                                  extrapolated from the rise.  [default: sd]
  --onset-sd FLOAT                Baseline SD multiple for --onset sd.
                                  [default: 2.0]
  --onset-fraction FLOAT          Amplitude fraction for --onset peak.
                                  [default: 0.2]
  --onset-min-samples INTEGER     Consecutive samples above threshold required
                                  for an onset.  [default: 3]
  --extrapolate-range <FLOAT FLOAT>...
                                  Amplitude fractions LOW HIGH bounding the
                                  rise fitted for --onset extrapolate.
                                  [default: 0.2, 0.8]
  --smooth INTEGER                Odd moving-average window in samples used to
                                  find peaks, onsets, decays and offsets. 1
                                  turns it off.  [default: 1]
  --decay-fraction FLOAT          Amplitude fraction the trace must fall to
                                  after the peak.  [default: 0.5]
  --min-trials INTEGER RANGE      Trial groups with fewer trials get empty
                                  session, reliability and mean-trace metrics.
                                  [default: 10; x>=1]
  --mask-response / --no-mask-response
                                  End cue-aligned reliability epochs at each
                                  trial's response, or at the median response
                                  time for trials without one.  [default:
                                  mask-response]
  --min-rt FLOAT RANGE            Drop trials with a response time below this,
                                  in seconds, from the reliability metrics.
                                  [default: 0.2; x>=0]
  --response-sd FLOAT             Baseline SD multiple a trial's mean epoch
                                  response must exceed for response_fraction.
                                  [default: 2.0]
  --time-warp                     Resample each reliability epoch onto a
                                  common 0-1 grid.
  --cue-baseline <FLOAT FLOAT>...
                                  Baseline window START END relative to each
                                  trial's cue, for lever-aligned reliability
                                  metrics.  [default: -1.0, 0.0]
  --bootstrap INTEGER RANGE       Resamples of each trial group for the mean-
                                  trace metrics and their intervals. 0 skips
                                  them.  [default: 10000; x>=0]
  --ci FLOAT RANGE                Width of the mean-trace metric intervals, in
                                  percent.  [default: 95.0; 0<x<100]
  --seed INTEGER                  Random seed for the bootstrap resamples.
                                  [default: 42]
  --help                          Show this message and exit.

    peri-event

    Cut per-trial windows around a behavioural event.

    RECORDING_PATH is a behaviour-aligned HDF5 recording or _regions.csv, and TRIALS_PATH the _trials.csv from visiomode-analysis. Choose the event with --event and the window with --pre and --post. Writes _event-_perievent.h5 for HDF5 input, or a long-format _event-_perievent.csv with the trials columns for CSV input.

    Usage:

    mesoscopy process peri-event [OPTIONS] RECORDING_PATH TRIALS_PATH

    Options:

      -o, --out_dir PATH              Output directory for the peri-event windows.
  --event [cue_onset|trial_start|response|reward]
                                  Behavioural event to align windows to.
                                  [default: cue_onset]
  --pre FLOAT                     Seconds before the event.  [default: 1.0]
  --post FLOAT                    Seconds after the event.  [default: 3.0]
  --fs FLOAT                      Sampling rate of the output windows, in Hz.
                                  [default: 25.0]
  --method [interp|nearest]       Resample by linear interpolation or by
                                  taking the nearest recorded sample.
                                  [default: interp]
  --baseline <FLOAT FLOAT>...     Baseline window START END in seconds from
                                  the event, whose mean is subtracted from
                                  each trial.
  --with-metrics                  Also write the `process metrics` tables. CSV
                                  input only.
  --response <FLOAT FLOAT>...     Response window START END, seconds relative
                                  to the event, end inclusive. Defaults to all
                                  post-event samples.
  --onset [sd|peak|extrapolate]   Onset by a baseline SD threshold, an
                                  amplitude fraction threshold, or a line
                                  extrapolated from the rise.  [default: sd]
  --onset-sd FLOAT                Baseline SD multiple for --onset sd.
                                  [default: 2.0]
  --onset-fraction FLOAT          Amplitude fraction for --onset peak.
                                  [default: 0.2]
  --onset-min-samples INTEGER     Consecutive samples above threshold required
                                  for an onset.  [default: 3]
  --extrapolate-range <FLOAT FLOAT>...
                                  Amplitude fractions LOW HIGH bounding the
                                  rise fitted for --onset extrapolate.
                                  [default: 0.2, 0.8]
  --smooth INTEGER                Odd moving-average window in samples used to
                                  find peaks, onsets, decays and offsets. 1
                                  turns it off.  [default: 1]
  --decay-fraction FLOAT          Amplitude fraction the trace must fall to
                                  after the peak.  [default: 0.5]
  --min-trials INTEGER RANGE      Trial groups with fewer trials get empty
                                  session, reliability and mean-trace metrics.
                                  [default: 10; x>=1]
  --mask-response / --no-mask-response
                                  End cue-aligned reliability epochs at each
                                  trial's response, or at the median response
                                  time for trials without one.  [default:
                                  mask-response]
  --min-rt FLOAT RANGE            Drop trials with a response time below this,
                                  in seconds, from the reliability metrics.
                                  [default: 0.2; x>=0]
  --response-sd FLOAT             Baseline SD multiple a trial's mean epoch
                                  response must exceed for response_fraction.
                                  [default: 2.0]
  --time-warp                     Resample each reliability epoch onto a
                                  common 0-1 grid.
  --cue-baseline <FLOAT FLOAT>...
                                  Baseline window START END relative to each
                                  trial's cue, for lever-aligned reliability
                                  metrics.  [default: -1.0, 0.0]
  --bootstrap INTEGER RANGE       Resamples of each trial group for the mean-
                                  trace metrics and their intervals. 0 skips
                                  them.  [default: 10000; x>=0]
  --ci FLOAT RANGE                Width of the mean-trace metric intervals, in
                                  percent.  [default: 95.0; 0<x<100]
  --seed INTEGER                  Random seed for the bootstrap resamples.
                                  [default: 42]
  --help                          Show this message and exit.

    regions

    Extract the mean ∆F/F of each brain region.

    PATH is a registered HDF5 or NWB recording. Pass -m to use your own region masks instead of the Allen atlas regions, and --include-aba to keep both. Writes _regions.csv with the mean trace of each region.

    Usage:

    mesoscopy process regions [OPTIONS] PATH

    Options:

      -o, --out_dir PATH  Output directory for the region activity file.
  -m, --mask PATH     Region mask file in NPY, NPZ or TIFF format, drawn on
                      the registered frames. Repeat to add more files.
  --include-aba       Extract the atlas regions alongside the -m masks.
  --help              Show this message and exit.

    regression

    Regress behavioural variables onto each ∆F/F pixel.

    RECORDING_PATH is an HDF5 or NWB ∆F/F recording and REGRESSOR_PATH an NPZ or HDF5 file of regressors. Add regressors recorded on another clock with -n. Writes _regression.npz with the coefficients, R² and mean squared error of each pixel.

    Usage:

    mesoscopy process regression [OPTIONS] RECORDING_PATH REGRESSOR_PATH

    Options:

      -o, --out_dir PATH              Output directory for the regression results.
  -a, --alpha FLOAT               Ridge regularisation strength.  [default:
                                  1.0]
  -n, --nuisance-regressors PATH  Nuisance regressor file in NPZ or HDF5
                                  format, such as motion energy. Repeat to add
                                  more files.
  -f, --fast                      Use the faster, experimental vectorised
                                  solver.
  --npz                           Save the results as a compressed NPZ file.
                                  This is the default.
  --h5                            Save the results as an HDF5 file.
  --help                          Show this message and exit.

    smooth

    Smooth a ∆F/F recording.

    PATH is an HDF5 or NWB ∆F/F recording. Set the width of the Laplacian-of-Gaussian filter with --sigma. Writes _smoothed.h5.

    Usage:

    mesoscopy process smooth [OPTIONS] PATH

    Options:

      -o, --out_dir PATH   Output directory for the smoothed recording.
  -s, --sigma INTEGER  Standard deviation of the Gaussian kernel, in pixels.
                       [default: 2]
  --help               Show this message and exit.

    zscore

    Z-score a ∆F/F recording pixel by pixel.

    PATH is an HDF5 or NWB ∆F/F recording. Writes _zscored.h5, and adds it to PATH when PATH is an NWB file.

    Usage:

    mesoscopy process zscore [OPTIONS] PATH

    Options:

      -o, --out_dir PATH  Output directory for the z-scored recording.
  --help              Show this message and exit.

    register

    Register recordings to an anatomical template.

    Usage:

    mesoscopy register [OPTIONS] COMMAND [ARGS]...

    Options:

      --help  Show this message and exit.

    Subcommands

    • label: Mark anatomical landmarks on a recording.
    • landmarks: Register a recording to the Allen CCF template.

    label

    Mark anatomical landmarks on a recording.

    PATH is a preprocessed HDF5 or NWB recording. Drag each landmark onto its anatomical location in the napari window that opens, then press Save and Close. Writes _landmarks.csv for register landmarks.

    Usage:

    mesoscopy register label [OPTIONS] PATH

    Options:

      -o, --out_dir PATH          Output directory for the landmarks file.
  -t, --template-points FILE  Template landmarks in CSV or Fiji XML points
                              format, instead of the Allen CCF landmarks.
  --session-id TEXT           Session ID naming the landmarks file. Defaults
                              to the name of PATH.
  --help                      Show this message and exit.

    landmarks

    Register a recording to the Allen CCF template.

    PATH is a preprocessed HDF5 or NWB recording with landmarks marked by register label. The landmarks file is found next to PATH or in --out_dir, or given with -r. Writes _registered.h5, and links it into PATH when PATH is an NWB file.

    Usage:

    mesoscopy register landmarks [OPTIONS] PATH

    Options:

      -o, --out_dir PATH           Output directory for the registered recording.
  -r, --recording-points FILE  Recording landmarks in CSV or Fiji XML points
                               format.
  -t, --template-points FILE   Template landmarks in CSV or Fiji XML points
                               format, instead of the Allen CCF landmarks.
  -s, --scale FLOAT            Scale of the Allen CCF template relative to its
                               native 140x142 pixels. Defaults to the scale
                               that keeps the recording's resolution. Ignored
                               with -t.
  --output-width INTEGER       Width of the registered frames. Deprecated in
                               favour of --scale.
  --output-height INTEGER      Height of the registered frames. Deprecated in
                               favour of --scale.
  --help                       Show this message and exit.

    report

    Generate an HTML report for a pipeline stage.

    PATH is a _preprocessed.h5, _registered.h5 or *_perievent.csv file. A peri-event report also shows the metrics and connectivity tables if found next to PATH. Writes _report.html.

    Usage:

    mesoscopy report [OPTIONS] PATH

    Options:

      -o, --out_dir PATH  Output directory for the report.
  -t, --trials FILE   Trials CSV giving sdt_type per trial, for peri-event
                      files without it.
  --help              Show this message and exit.

    sample

    Save one frame of an HDF5 recording as a PNG.

    PATH is an HDF5 recording and OUT_DIR the directory for the image. Pick the frame with --index and its dataset with --key. Writes _sample-.png.

    Usage:

    mesoscopy sample [OPTIONS] PATH OUT_DIR

    Options:

      --index INTEGER  Index of the frame to save.  [default: 0]
  --crop INTEGER   Pixels to crop from each edge.  [default: 0]
  --vmin FLOAT     Lower end of the colour scale.  [default: 0]
  --vmax FLOAT     Upper end of the colour scale.  [default: 255]
  --key TEXT       Dataset holding the frames, such as F or frames.
  --help           Show this message and exit.

    start-time

    Print a recording's start time.

    PATH is an HDF5 recording or an NWB file. Prints the first frame timestamp of an HDF5 file, or the session start time of an NWB file.

    Usage:

    mesoscopy start-time [OPTIONS] PATH

    Options:

      --help  Show this message and exit.
